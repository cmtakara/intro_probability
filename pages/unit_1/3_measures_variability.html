Standard Deviation

Variance

Formulas

  • Population - sigma^2 = summation over population(xi[data point] - mu)^2/N (N is number of data points in population)
    • sigma^2 - population variance
    • N - number of data points in the population
    • xi - each individual data point
    • mu - population mean
  • Sample - s^2 = summation over sample(xi[data point] - xbar)^2/(n-1) (n is number of data points in sample)
    • s^2 - sample variance
    • n - number of data points in the sample
    • xi - each individual data point
    • xbar - sample mean
